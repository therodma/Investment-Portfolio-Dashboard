# Portfolio Intelligence Dashboard

> 🌐 **Live Demo:** [https://ais-pre-l7twyehgmtb54sdiprh54c-263800642829.us-east5.run.app](https://ais-pre-l7twyehgmtb54sdiprh54c-263800642829.us-east5.run.app)

A full-stack, professional investment portfolio management and analytics platform with real-time market data quotes, interactive data visualisations, and AI-powered portfolio insights powered by Google Gemini.

---

## 🚀 Features

- **Live Market Pricing & Quotes**: Real-time market quote engine with TTL caching and on-demand refresh triggers for held securities.
- **AI-Powered Portfolio Analysis**: Contextual, objective portfolio audits generated by Google's Gemini models (`gemini-2.5-flash`), with automated fallback analytical heuristics.
- **Portfolio Health Metrics**: Instant tracking of Total Value, Unrealized Gains/Losses, Day Change, Diversification Index, and Concentration Risk.
- **Interactive Visualizations**:
  - Asset and sector allocation charts via Recharts
  - Historical performance trajectories
  - Dynamic risk distribution breakdowns
- **Holdings Management**:
  - Add, edit, and delete positions across global stocks and ETFs
  - Track cost basis, current market value, individual P&L, and portfolio weight
  - Real-time ticker search and quote inspection modals
- **Multi-User Authentication**: Secure user session support with user-isolated portfolios.

## 🛠️ Tech Stack

- **Frontend**:
  - React 19 + TypeScript
  - Tailwind CSS v4

  - Motion for fluid UI transitions

- **Backend**:
  - Node.js & Express

## 📦 Getting Started

### Prerequisites

- Node.js 18+ or Bun
- npm or bun package manager

### 1. Installation

Clone the repository and install dependencies:

```bash
git clone <repository-url>
cd <repository-directory>
npm install
```

### 2. Environment Variables

Create a `.env` file from `.env.example`:

```bash
cp .env.example .env
```

Configure your environment variables:

```env
PORT=3000
GEMINI_API_KEY=your_gemini_api_key_here
```

*(Note: The AI analysis feature gracefully falls back to an algorithmic rules engine if `GEMINI_API_KEY` is not provided).*

### 3. Development Server

Start the full-stack development server:

```bash
npm run dev
```

The application will be accessible at `http://localhost:3000`.

### 4. Production Build

Build and run for production:

```bash
npm run build
npm start
```
